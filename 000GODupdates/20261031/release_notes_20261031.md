## 一、本次更新内容与 Bug 修复明细

### 1. 服务端 GameServer 核心引擎升级
- **更新文件**：`GameServer_20250527_Update.exe` -> 替换到 `Mirserver\Mir200\GameServer.exe`
- **核心修复项**：
  1. **解决网关频繁断线**：优化心跳包检测机制，彻底消除每隔 100 秒客户端异常断线的 Bug。
  2. **修复技能书无法学习**：同步了 2025-01-06 最新核心逻辑，解决双击技能书无法触发学习的严重缺陷。
  3. **修复假怪/尸体不消失**：修复特定怪物死亡后残余模型/无碰撞死体常驻地图的缺陷。
  4. **修复组队成员为0时队伍未释放**：解决因空队伍泄漏导致的内存增加和异常广播问题。
  5. **修复关服弹窗报错**：修复正常维护关闭 GameServer 时由于多线程资源未释放导致的内存访问违例报错。
  6. **修复永久属性持久化**：支持 `usebonuspoint` 命令，并通过数据库 `BonusAbil` 字段完整读写保存。

### 2. 运行网关 RunGate 防卡死补丁
- **更新文件**：`RunGate_0530_AntiHang_Update.exe` -> 替换到 `Mirserver\RunGate\RunGate.exe`
- **核心修复项**：
  1. **彻底解决网关无响应假死**：重构了高并发连接下的套接字缓冲区处理，防止客户端发送特定大数据包时网关挂起。
  2. **网络重连优化**：增强网络抖动时的平滑恢复能力，减少掉线重连导致的连接池占满。

### 3. PC客户端最新引擎同步

  3. 优化退出按钮机制，彻底释放 CEF 与 Direct3D 资源并退出进程。
